Kebijakan Privasi Ngaji

Berlaku sejak 30 Oktober 2026

Ngaji adalah aplikasi untuk membaca Al-Qur'an beserta sejarah ayat, hadist penjelas, dan tag pembahasan. Kebijakan ini menjelaskan data apa saja yang digunakan aplikasi.

Ringkasan

  • Aplikasi tidak meminta akun, nama, email, nomor telepon, lokasi, kontak, maupun izin kamera atau mikrofon.
  • Aplikasi tidak memuat iklan, analitik, atau pelacak pihak ketiga.
  • Kami (pengembang) tidak mengumpulkan, menyimpan, menjual, atau membagikan data pribadi Anda.

Data yang tersimpan di perangkat Anda

Data berikut hanya disimpan di penyimpanan internal aplikasi pada perangkat Anda dan tidak dikirim ke server mana pun:

  • Catatan sejarah ayat, hadist, dan tag yang Anda tulis sendiri;
  • Penanda (bookmark) ayat;
  • Salinan teks Al-Qur'an, terjemahan, tafsir, dan bab kitab hadist yang pernah dibuka, agar dapat dibaca tanpa internet.

Semua data ini terhapus ketika Anda menghapus data aplikasi atau meng-uninstall aplikasi.

Koneksi internet

Aplikasi menggunakan izin internet hanya untuk mengunduh teks dari layanan publik berikut:

  • equran.id, untuk teks Al-Qur'an, terjemahan, dan Tafsir Kemenag RI;
  • jsDelivr, untuk teks kitab hadist dari proyek terbuka hadith-api;
  • GitHub, untuk pembaruan konten kajian (sejarah ayat, hadist penjelas, dan tema).

Permintaan tersebut tidak menyertakan data pribadi maupun catatan Anda. Seperti server web pada umumnya, server layanan tersebut dapat mencatat informasi teknis standar seperti alamat IP; hal tersebut diatur oleh kebijakan masing-masing layanan.

Anak-anak

Aplikasi ini dapat digunakan oleh semua usia dan tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di halaman ini dengan tanggal berlaku yang diperbarui.
